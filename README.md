
# 🌍 AI Trip Planner

**AI Trip Planner** is a smart and intuitive web application built using the MERN stack that helps users plan personalized travel itineraries using the power of Artificial Intelligence. Just tell us your destination, travel dates, and preferences — and get a complete trip plan instantly!

## 🚀 Features

* 🧠 **AI-powered itinerary generation** using the Gemini API
* 📍 **Location-based suggestions** for attractions, food, and activities
* 💼 **User authentication** for saved plans and personalized access
* 🎒 **Responsive design** for seamless use across devices
* 🗺️ **Interactive map integration** to visualize travel plans
* 📅 **Day-wise travel schedule** with time and activity breakdown
* 💬 **User-friendly interface** for smooth input and results

## 🛠 Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT (JSON Web Tokens)
* **AI Integration:** Gemini API (Google’s LLM)
* **Deployment:** Vercel
